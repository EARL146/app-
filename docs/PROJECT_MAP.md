# Project Map

## High-level architecture

- `lib/main.dart` - Application entry point.
- `lib/app_shell.dart` - Foundation app shell and session bootstrap.
- `lib/navigation/app_routes.dart` - Route constants.
- `lib/constants/` - Colors and theme definitions.
- `lib/services/` - API, auth, and storage services.
- `lib/models/` - Data models for users, products and orders.
- `lib/screens/` - UI screens to be implemented.
- `lib/widgets/` - Shared reusable screen widgets.
